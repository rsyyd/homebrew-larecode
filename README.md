# Homebrew tap for Lare Code

This tap provides the Homebrew formula for [Lare Code](https://github.com/rsyyd/larecode), an open-source AI coding agent for the terminal.

## Install

```bash
brew tap rsyyd/larecode
brew install larecode
```

## About

The formula is generated automatically from the release binaries on every tagged release. It installs the prebuilt binary for your platform (macOS Intel, macOS Apple Silicon, or Linux x86_64).
